# Daily English · 阶段驱动英语学习系统

这是一个纯 Web、本地运行的英语学习网站。新版把排课原则改为“阶段先于时长”：先由当前学习阶段决定允许出现的任务类型，再由 45 / 90 / 150 分钟决定练习数量和深度。

## 当前版本

- `normalized` 文件夹中的 70 份 Markdown 已全部转换到 `public/data/english2/normalized_course.json`，成为学习系统的课程主体，旧版通用演示文章和 1,840 词工作簿不再驱动排课。
- 新增“英语二资料”入口，可以按类别搜索并阅读基础语法、教材、词汇、词组、写作、题型技巧、专项练习、模拟卷和历年真题全文。
- 12 周阶段路线：
  - 第 1-3 周：normalized 基础语法、高频词和基础句型。
  - 第 4-5 周：教材、核心词组和句子结构。
  - 第 6-8 周：阅读、教材与写作专项。
  - 第 9-10 周：题型技巧、专项练习和 2014 年后的常见新题型真题。
  - 第 11-12 周：模拟、冲刺资料、错题回收及历史真题拓展。
- 每个阶段分别定义 45 / 90 / 150 分钟模板；150 分钟主要增加复习、听写、改错、阅读和输出，不按比例增加新词。
- 每周节奏为 4 天新内容 + 1 天综合 + 1 天检测/补救 + 1 天休息或轻复习。
- 到期复习优先；积压时减少新词和新内容，而不是删除复习。
- 阶段晋级按词汇辨认、发音/听辨、基础语法、简单句、阅读、翻译/写作分别判断，不用平均分掩盖关键基础缺失。
- 默认零基础从第 1 阶段开始；起点校准和设置页允许选择更高起点。
- 课程总路线为 84 天，每天引用一份 normalized 来源资料；70 份原文件全部至少进入一次路线，其余日期用于重点资料回看。
- 每日新增单词有统一硬上限：45 分钟最多 15 个、90 分钟最多 25 个、150 分钟最多 30 个；重点词和扩展词合计不得超过 30，到期复习不计入新增上限。
- 词汇包含分级、词性、音标、中文义、简单例句和学习状态；离线词典词条不等于已学词。
- 所有英文词可点击查询；保留 1,286 词离线英汉词典、浏览器发音和在线补充词典。
- IndexedDB 保存学习记录，支持 JSON 导入导出，并兼容旧版 v2/v3/v4 与更早 localStorage 数据迁移。
- 只统计真实完成记录，不制造演示数据。
- 保持通用主题，不绑定个人游戏、二次元等偏好。
- 纯 Web 本地运行，不包含 Electron 或 Windows 桌面运行时。

## 课程内容来源（当前）

当前学习路线只使用《英语（二）自学教程》（2012 年版，课程代码 00015，张敬源、张虹主编）的本地提取内容：Unit 1–12、教材自测和教材词汇附录，共 14 份课程文件。外部基础语法 PDF、历年真题、旧词表和其他资料不会再进入今日计划、学习页、练习或复习排期。

课程数据位于 `public/data/english2/textbook_course.json`，由下列命令从 `app/study/textbook-units/main-textbook-manifest.json` 重新生成：

```text
npm run content:build
```

教材词汇目前提取到 255 个有效词条；每个词的首次排期不超过 30 个/天。保留的 1,286 词离线词典只用于点击查词、发音和释义补充，不会作为课程内容自动排期。

## 13000 考试大纲中心

“考试大纲”入口提供 13000 英语（专升本）的课程事实、来源登记、大纲骨架、学习范围、题型说明和教材映射状态。当前已由 2026 全国统考目录、2026 上海市教育考试院目录和中国教育考试网历史目录交叉确认：课程代码为 `13000`，课程名称为“英语（专升本）”，对应《英语（二）自学考试大纲》和张敬源、张虹主编的《英语（二）自学教程》（外语教学与研究出版社，2012 年版）。

完整大纲正文、江西现行题型/题量/分值/时长和教材逐单元映射尚未取得足够的合法核验材料，因此数据文件中明确标为 `pending`，页面不会显示推测数字，也不会把待核验节点计入正式覆盖率。来源登记位于 `public/data/exam/`，不复制教材、大纲或来源不明题库。

### 当前词汇与词组

转换脚本从 normalized 的《高频600单词》中提取、去重并排期词汇候选，从《核心300词组》中提取词组候选。由于原资料存在重复编号、OCR 拼写和音标错误，这些内容统一标记为用户资料 `provisional`，不会冒充官方完整词表。离线词典仅用于补充发音、释义和查词，不再把整个词典自动加入新词计划。

重新生成资料数据：

```text
npm run content:build
```

脚本会检查 70 份文件是否全部进入转换结果、记录每份文件 SHA-256，并确保任何一天的首次排期不超过 30 个单词。

## 本地运行

需要 Node.js `>=22.13.0`。

### Windows 一键启动

解压后双击项目根目录中的：

```text
START_ENGLISH.cmd
```

启动器会检查 Node.js，首次运行时安装依赖，启动本地服务，并在服务就绪后打开默认浏览器。默认双击后会静默运行，不需要一直保留命令窗口；运行日志写入 `.runtime/server.out.log` 和 `.runtime/server.err.log`。如果上次安装被中断，启动器会自动使用可恢复的依赖安装方式，避免 Windows 下 `ENOTEMPTY` 清理失败。重复双击时会复用已运行的网站，不会再次启动一个占用相同端口的进程。

需要排查启动问题时，双击 `START_ENGLISH_DEBUG.cmd` 查看前台日志。要设置当前 Windows 用户登录后自动启动，双击 `INSTALL_ENGLISH_STARTUP.cmd`；取消开机启动则双击 `REMOVE_ENGLISH_STARTUP.cmd`。这仍然是本地 Web 服务，不会安装 Electron 或系统服务。

### 手动启动

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。默认一键启动使用 `localhost:4173`。

## Docker 生产部署（静态 Nginx + PostgreSQL API）

服务器需要先加入现有 PostgreSQL 容器所在的 Docker 网络。当前项目默认使用 `nekro_network` 和数据库容器 `nekro_postgres`。

在项目目录创建仅存在于服务器的 `.env`：

```bash
cp .env.example .env
sed -i 's/^APP_PASSWORD=.*/APP_PASSWORD=请替换为学习空间访问密码/' .env
sed -i 's/^PGPASSWORD=.*/PGPASSWORD=请替换为PostgreSQL密码/' .env
```

确认 `.env` 没有被提交后启动：

```bash
docker compose up -d --build
docker compose ps
docker compose logs -f --tail=100
```

一键验收部署状态：

```bash
bash scripts/verify-docker-deployment.sh
```

访问 `http://服务器IP:4173`。页面由 Nginx 提供，`/api` 请求转发到单用户 API，学习状态同时保存在 PostgreSQL 和浏览器 IndexedDB 中。第一次登录使用 `.env` 中的 `APP_PASSWORD`。

更新版本：

```bash
git pull origin main
docker compose up -d --build
```

数据只保存在数据库中时，`docker compose down` 不会删除数据。不要使用 `docker compose down -v`，也不要删除 `nekro_postgres` 的数据卷。

## 数据说明

学习记录仅保存在当前浏览器。换电脑或清理浏览器数据前，请在“设置 → 备份与恢复”中导出 JSON 文件。导入旧备份时，系统会迁移到 `schemaVersion: 5`，保留历史分钟、完成记录、错题和复习卡，并清除指向旧课程 ID 的未完成今日计划。
